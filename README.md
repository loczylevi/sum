# Python gyakorló feladatsor – Összegzés tétele

## 1. feladat – Lista elemeinek összeadása

Készíts egy programot, amely létrehoz egy listát 7 darab egész számmal!

A program:
- Adja össze a lista elemeit!
- Írja ki az összegüket!
- Írja ki a lista elemeit!

**Példa kimenet:**
```text
A lista elemei: [4, 8, 2, 6, 1, 9, 3]
A számok összege: 33
```

## 2. feladat – Véletlen számok összeadása

Készíts egy programot, amely 5 darab véletlen egész számot generál az [1;20] intervallumban!

A program:
- Tárolja el a számokat egy listában!
- Adja össze a lista elemeit!
- Írja ki a generált számokat és az összegüket!

**Példa kimenet:**
```text
Generált számok: [5, 12, 3, 8, 2]
A számok összege: 30
```

## 3. feladat – Páros számok összege

Készíts egy programot, amely az alábbi listából csak a páros számokat adja össze!

```python
szamok = [3, 12, 5, 8, 7, 14, 1, 6]
```

A program írja ki:
- A lista elemeit!
- A páros számok összegét!

**Példa kimenet:**
```text
A lista elemei: [3, 12, 5, 8, 7, 14, 1, 6]
A páros számok összege: 40
```

## 4. feladat – Számok bekérése

Írj egy programot, amely egész számokat kér be a felhasználótól!

A bekérés addig tartson, amíg a felhasználó 0-t nem ad meg.

A program:
- Adja össze a bekért számokat!
- Számolja meg, hány számot adott meg a felhasználó!
- Írja ki az összeget és a darabszámot!

A 0 ne számítson bele az összegbe és a darabszámba!

**Példa futás:**
```text
Adj meg egy számot: 5
Adj meg egy számot: 8
Adj meg egy számot: 3
Adj meg egy számot: 0

A számok összege: 16
Megadott számok darabszáma: 3
```

## 5. feladat – Jegyek átlaga

Készíts egy programot, amely bekéri a felhasználó érdemjegyeit!

A bekérés 0 megadásáig tartson.

A program:
- Számolja meg a megadott jegyeket!
- Adja össze a jegyeket!
- Számítsa ki az átlagot!
- Ha a felhasználó egyetlen jegyet sem adott meg, írja ki, hogy nem adott meg jegyet!

**Példa futás:**
```text
Add meg az első jegyet: 5
Add meg a következő jegyet: 4
Add meg a következő jegyet: 3
Add meg a következő jegyet: 0

A jegyeid átlaga: 4.0
```

## 6. feladat – Intervallum ellenőrzése

Írj egy programot, amely egész számokat kér be a felhasználótól!

A bekérés akkor fejeződjön be, amikor a felhasználó a [-5;5] intervallumon kívüli számot ad meg.

A program:
- Tárolja el a megfelelő intervallumba eső számokat egy listában!
- Adja össze ezeket a számokat!
- Írja ki a listát és az összegüket!

**Példa futás:**
```text
Adj meg egy számot: 3
Adj meg egy számot: -2
Adj meg egy számot: 5
Adj meg egy számot: 1
Adj meg egy számot: 8

A megfelelő számok: [3, -2, 5, 1]
A számok összege: 7
```

## 7. feladat – Páros számok összege véletlen számokból

Készíts egy programot, amely 10 darab véletlen egész számot generál az [1;50] intervallumban!

A program:
- Tárolja el a számokat egy listában!
- Határozza meg a páros számokat!
- Adja össze a páros számokat!
- Írja ki a lista elemeit és a páros számok összegét!

**Példa kimenet:**
```text
Generált számok: [4, 7, 12, 3, 8, 15, 2, 9, 6, 11]
Páros számok összege: 32
```
